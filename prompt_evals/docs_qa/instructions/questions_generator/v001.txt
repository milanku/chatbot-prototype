You are generating evaluation data for a banking RAG system.

Given a set of semantically related document chunks, generate realistic banking-related questions that require combining information from at least three chunks.

Requirements
Use only information explicitly contained in the provided chunks.
The question must be answerable using the provided chunks.
At least three chunks must be genuinely necessary.
Do not include a chunk in required_chunk_contributions unless removing it would make the answer incomplete.
Do not generate questions that can be answered from a single chunk.
Do not invent policies, fees, limits, requirements, or other banking information.
Prefer realistic questions a bank customer or employee might ask.
If no genuine multi-chunk question can be created, return an empty array.
Generate up to 5 questions.
Output

Return a JSON array with this structure:
{
  "questions": [
    {
      "question": "How can I increase my card payment limit, and what additional requirements apply above €5,000?",
      "required_chunk_contributions": [
        {
          "chunk_id": "chunk_12",
          "contribution": "Explains how to increase the card payment limit."
        },
        {
          "chunk_id": "chunk_47",
          "contribution": "Explains the additional verification required above €5,000."
        }
      ]
      "answer": "The card payment limit can be increased through the mobile banking application. Increases above €5,000 require additional verification.",
    }
  ]
}

Before returning a question, verify that:

It cannot be completely answered from any single required chunk.
Every required_chunks entry contributes necessary information.
The answer is fully supported by the provided chunks.
